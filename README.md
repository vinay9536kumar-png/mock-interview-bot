# AI Mock Interview Bot

An AI-powered mock interview tool for job seekers. Upload your resume, paste a job description, and practice with interview questions tailored to that role. Every answer is scored and comes with feedback and a model answer.

## Download
- Download the latest version: [Releases](https://github.com/vinay9536kumar-png/mock-interview-bot/releases/latest)
- Or clone it:

`git clone https://github.com/vinay9536kumar-png/mock-interview-bot.git`

## Features

- Resume parsing from PDF using PyMuPDF
- Role-specific technical, project-based and HR questions generated by Google Gemini
- Instant scoring (0-10) for every answer
- Strengths, improvements and an ideal answer for each question
- Final score summary at the end of the interview
- Simple Streamlit web interface
- Automatic retry and backup model when the API is busy

## How It Works

1. Upload your resume (PDF) and paste the job description.
2. The bot reads your resume and generates interview questions for that role.
3. Answer each question in the text box.
4. Gemini evaluates your answer and returns a score with detailed feedback.
5. See your final score and review all feedback at the end.

## Tech Stack

- Python 3.12
- Streamlit
- Google Gemini API (`google-genai`)

## Run Locally

1. Create and activate a virtual environment:

```
python -m venv venv
venv\Scripts\activate
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Get a free Gemini API key from [Google AI Studio](https://aistudio.google.com/) and create a `.env` file in the project folder:

```
GEMINI_API_KEY=your_api_key_here
```

4. Start the app:

```
streamlit run app.py
```

## Command-Line Mode

You can also practice in the terminal. Put `resume.pdf` and `jd.txt` in the project folder, then run:

```
python evaluate.py
```
